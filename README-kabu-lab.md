# KABU LAB

ローカルで動く株価・IR確認アプリです。既存の `stock-alert.html` は使わず、新規アプリとして動きます。

## ファイル

- `kabu-lab.html`
  - アプリ本体
- `kabu-lab-proxy.ps1`
  - Yahoo Finance系データとTDnet IR取得用のローカルプロキシ
- `start-kabu-lab.bat`
  - 起動用バッチ

## できること

- 日本株 / 米国株の登録
- 日本株のTDnet IR自動取得
- PER / PBR / EPS / 時価総額の表示
- JPX公式の決算発表予定日Excelから取得できる場合、次回決算発表予定日を自動表示
- RSI(14) / SMA / MACD / 支持線 / 抵抗線 / 年率ボラティリティの表示
- 決算重視の投資分析レポート生成
- 選択したIR PDF URLを差し込んだChatGPT用プロンプト作成
- 決算短信、決算説明資料、業績修正/配当IR向けのテンプレート切替
- 作成したIRプロンプト履歴の保存と再コピー
- 作成したIRプロンプトのMarkdown保存
- ChatGPT Webの回答メモ保存、再コピー、Markdown保存
- 決算イベント管理、分析チェックリスト、Bull/Bear/Watchメモ
- 保存済みAI回答メモのIR差分ビュー
- 銘柄別ダッシュボードで決算予定、確認進捗、AI回答、Bull/Bear/Watchを一覧化
- 保有銘柄、お気に入り、その他のグループ分けと表示フィルター
- Yahoo掲示板と株探ページへの外部リンク
- ChatGPT Web版へ貼り付けるためのレポートコピー
- JSONエクスポート / インポート

## 起動方法

`start-kabu-lab.bat` を実行してください。

正常に起動すると、ローカルプロキシとHTML画面が開きます。接続表示が `127.0.0.1:8809 / v2026-04-25.7` なら最新版です。

## 使い方

1. 銘柄コードを追加する
2. `価格/分析更新` で株価とテクニカルを取得する
3. 日本株は `IR一括更新` でIRを取得する
4. 分析タブでIRとテンプレートを選び、`決算IRプロンプトをコピー` を押す
5. 必要なら `分析レポートを生成` または `ChatGPT用レポートをコピー` を使う

## ポイント

- OpenAI APIキーは不要です
- API課金も不要です
- レポートはアプリ内ルールでローカル生成します
- 日本株のPER/PBR/EPSは、Yahoo quote APIが失敗した場合でもYahoo Japan銘柄ページから補完します
- 事業内容、競合、市場シェア、ROE/ROIC、FCFなど未取得データは「要確認」として表示します
- 最終判断は必ずIR本文や公式資料で確認してください

## セキュリティ

- プロキシは `127.0.0.1` のみで待ち受けます
- 任意URLへ飛ぶ汎用プロキシではありません
- 取得先はYahoo Finance系とTDnetの固定エンドポイントです
